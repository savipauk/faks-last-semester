komunkacija izmedu procesa (distributed):
- porukama
- rpc
- distributed memory space

pipelines
1) stvoriti pipeline
2) fork procesa
3) u forkanom proesu zatvoriti kraj za pisanje
3) u orig. proesu zatvoriti kraj za citanje

pipeline vs file
- p: r/w je fifo 
- f: pozicioniranje pointera za citanje -> nije fifo nego arbitrary
- p:
    - pisac ceka dok citac nekaj ne procita, citanje je destruktivno (konzumira)
    - ako je prazan citac mora cekati kj se zapise

cons 
- procesi moraju biti u srodstvu (parent-child)
- pipeline se mora stvoriti prije nego procesi vec postoje
- koriste buffer cache velicine 1 bloka

syscall: `int pipe(int fd[2])`
    fd[0] opisnik izlazne strane pipelinea. iz njega se vade podaci iz pipeline
    fd[1] pisanje

zatvaranje jednog kraja pipeline: `int close(int fdn)`
    fd(n): file descriptor (id). ali dela s pipeline

fd se moze duplicirati
0 stdin, 1 stdout, 2 stderr

`int dup(int fdn)`
vrati id kopije fd-a s id n
"The new descriptor returned by the call is the lowest numbered descriptor currently not in use by the process."
