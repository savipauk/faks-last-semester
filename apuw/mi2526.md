1) Razlika između URL-a i URN-a s obzirom na
a) pronalazak sredstva
URL - sadrzi informaciju o lokaciji i nacinu pristupa sredstvu
URN - identificira sredstvo unikatnim imenom

URL: https://example.com/documents/paper.pdf – govori gdje se dokument nalazi.
URN: urn:isbn:9780131103627 – identificira knjigu pomoću ISBN-a, neovisno o tome gdje se nalazi.

b) promjenu lokacije sredstva
URL - promjenom lokacije se mora promjeniti i URL
URN - URN nije vezan za lokaciju: lokacije se moze promjeniti bez promjene URNa

c) dostupnost sredstva na više različitih lokacija
URL - svaka lokacija ima svoj URL
URN - isto sredstvo ima isti URN ali moze biti dostupno na vise lokacija

3. Opisati i objasniti ponašanje modernog preglednika (Google Chrome, Mozilla...) za ispravno formatiran HTML
dokument, pri čemu se u zaglavnju zahtjeva nalazi:
a) Content-Type: text/html
renderira html stranicu onako kako je zamisljeno, sa svim elementima, css, javascript itd

b) Content-Type: text/plain
ne interpertira html i ostale tagove, vec doslovno ispisuje html file unutar browsera

c) Content-Type: application/xml
pokusava interpretirati html file kao xml, sto moze uspijeti ali ne mora. ako uspije, onda prikazuje xml stablo, a ako ne onda ima pogreske pa moze biti svasta. 

d) Content-Type: application/json
tretira html kao json podatke, a buduci da je krivi format onda prikazuje obican text kao text/plain
